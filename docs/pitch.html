HackSpain 2026

An agent firewall,
not a log viewer.

Inspect the tool call before it happens. Score the chain. Let code decide. A model never pulls the plug.

01 — Problem

Harm is a chain, and logs are late.

  • Agents read files, mint tools, call the network, write memory, schedule later effects.
  • A tool allowlist fails if the agent can register a new tool.
  • A single-event classifier misses slow burn: secrets now, exfil ten steps later.
  • If the monitor waits until after the side effect, the write already landed.

02 — Statements

Four rules we will not break.

Chain, not eventA curl is noise. Curl + .env + POST is intent.
Preflight, not afterthoughtEvery tool asks first: allow, hold, or refuse.
Signals, then codeJev, Sentinel, SafetyDrift, policy inform. Code decides.
Levels only go upNo auto-downgrade. L1 is sticky. A human clears.

03 — How we do it

Sit on the path. Keep the trail off-box.

  • Host-side capture. The sandbox cannot edit the tape.
  • Inspect before execute. Sensors run on the requested action.
  • Two memories for Jev. Recent tape + flagged nodes (level ≥ 1).
  • Two-tier when unsure. A watcher annotates. It cannot fire a playbook.
  • Fixed playbooks. Tag → supervise → pause this agent → cut egress → kill swarm. L4/L5 page on-call in parallel. The call is not permission.

04 — Conclusion

This product is a firewall.

  • It sits in front of every tool.
  • It inspects the request, then allows, delays, or refuses.
  • Containment is host-side: pause, drop token, disconnect the agent network.
  • The viewer stack stays up. The agent cannot un-pause itself.

05 — Challenges

What a naive filter will miss.

  • Covert chains — safe talk plus a hidden, renamed, delayed, or split write.
  • Minted tools — allowlists die when the agent writes new capabilities.
  • Slow burn — high-confidence “mild” while sparse exfil is already underway.
  • False positives — legitimate memory and compensating writes must pass.
  • Kill-switch blast — L1–L3 = one agent. L4–L5 = the environment, not the viewer.

06 — Architecture

One path. Four sensors. One gate.

07 — Sentinel

Graph rules, not another LLM.

  • Walks the causal neighborhood of the current event.
  • Fires versioned rules: unknown tool, unauthorized write, provenance upgrade, sensitive-read then network, write burst, over-cap, cross-channel reentry, stale authority, memory-as-permission, missing handoff.
  • A finding has a severity. The gate may raise the incident level.
  • Hard Sentinel / policy can refuse a preflight even when Jev is down.

08 — SafetyDrift

Monotonic state + Markov forecast.

  • Each event can only raise bands: data exposure, tool escalation, reversibility, authority, context integrity, blast radius.
  • State = (worst band, how many bands are elevated).
  • Forecasts p(violation) at 1, 3, 5 steps. The gate uses the 3-step forecast as trajectory risk.
  • HOLD if the path is already heading into harm, even if this event looks mild.
  • Live serving uses a prior. Fitting is eval-time only.
